# PINNED ON PURPOSE. Render installs the newest match on every build, so an
# unbounded range means an upstream release can break a deploy on a commit
# that changed nothing.
#
# Every line now carries an UPPER bound, which is what the note above always
# claimed and only streamlit actually had. Without it the floors had drifted
# badly — a build was resolving stripe 15.x against a >=11.0 floor and pandas
# 3.x against >=2.0, i.e. four majors and one major past what the comment
# called "the floor we test against". Nothing was broken (all 37 modules
# import cleanly against the versions below), but the next major of any of
# these would have landed straight in production on a commit that changed
# nothing.
#
# Upper bounds are the NEXT major, so patch and minor updates still flow in
# and only a breaking release is held back. Raising one is a deliberate
# commit: bump it, deploy, watch it.
